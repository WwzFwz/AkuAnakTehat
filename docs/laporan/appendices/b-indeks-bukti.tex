\subsection{Bukti setelah perbaikan 8 Oktober}
E9 merujuk \reliabilityevidence{README.md} beserta JSON k6, sampel koneksi, konfigurasi, log polling, serta keadaan container sebelum dan sesudah pengujian pada subfolder load. Angka P2 terbaru menggunakan kelompok bukti ini.

E10 merujuk \reliabilityevidence{regression.txt}, \reliabilityevidence{postgres.txt}, \reliabilityevidence{modules.txt}, dan \reliabilityevidence{secret-scan.txt}. Transkrip regresi sebelum pembaruan tes migrasi turut dipertahankan; kegagalan tersebut berasal dari asumsi versi migrasi tetap pada angka 2. Tes diperbaiki untuk memastikan versi aktual dan status migrasi tetap sama setelah restart. Regresi sesudahnya lulus. Manifest mencatat hash artefak dan normalisasi teks tanpa mengubah nilai pengukuran.
