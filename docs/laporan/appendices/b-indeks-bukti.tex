\subsection{Bukti pengujian akhir}
E9 merujuk \reliabilityevidence{README.md} beserta JSON k6, sampel koneksi, konfigurasi, log polling, serta keadaan container sebelum dan sesudah pengujian pada subfolder load. Angka P2 terbaru menggunakan kelompok bukti ini.

E10 merujuk \reliabilityevidence{regression.txt}, \reliabilityevidence{postgres.txt}, \reliabilityevidence{modules.txt}, dan \reliabilityevidence{secret-scan.txt}. Regresi stack lulus dalam 306,951 s. Manifest mencatat hash artefak dan normalisasi teks tanpa mengubah nilai pengukuran.

E11 merujuk \codepath{docs/evidence/http-attempts-2026-10-08/README.md}, yang memuat hasil tes module Client API dan go vet untuk verifikasi latency per percobaan HTTP. Bukti ini tidak menggantikan pengukuran k6 pada E9.
